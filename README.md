# APJ1_Bootcamp

Этот репозиторий содержит мои решения для трех проектов учебного курса Java Bootcamp.

## Проект 01. Умные утилиты

В этом проекте я изучал и применял базовые возможности языка Java. Проект представляет собой набор консольных утилит, которые решают различные математические и логические задачи.

**Что я реализовал:**
- **Математические вычисления:** расчет периметра треугольника по координатам, конвертацию секунд в формат времени, поиск чисел Фибоначчи с использованием рекурсии.
- **Работу с массивами и циклами:** поиск средних значений, сортировку массива методом выбора (без использования встроенных библиотечных методов), поиск минимума и максимума с чтением данных из текстового файла.
- **Обработку ввода-вывода:** во всех утилитах я настроил корректную обработку некорректного ввода. Программа не прерывается с ошибкой, а выводит сообщение и предлагает повторить ввод.
- **Работу со строками и коллекциями:** фильтрацию строк по подстроке (без использования Stream API, написал свою реализацию) и поиск совершеннолетних пользователей с применением Java Stream API.

## Проект 02. Pet Info

В этом проекте я углубился в объектно-ориентированное программирование, а также освоил функциональную парадигму и основы многопоточности. Проект моделирует систему учета информации о питомцах.

**Что я реализовал:**
- **Спроектировал иерархию классов:** создал абстрактный класс `Animal` и его наследников (`Dog`, `Cat`, `Hamster`, `GuineaPig`).
- **Применил полиморфизм и интерфейсы** (`Herbivore`, `Omnivore`) для расчета необходимого количества корма и определения специфического поведения животных.
- **Написал код в функциональном стиле:** реализовал задачу по увеличению возраста питомцев, используя `Stream API` и полностью отказавшись от операторов циклов.
- **Реализовал асинхронное отслеживание прогулок:** каждый питомец гуляет в отдельном потоке. Программа корректно ожидает завершения всех потоков и фиксирует время старта и окончания прогулки.
- **Написал собственный итератор** (`AnimalIterator`), реализующий кастомный интерфейс `BaseIterator` для обхода коллекции питомцев.

## Проект 03. Крестики-нолики (Spring Web)

Этот проект был посвящен созданию полноценного веб-приложения с использованием фреймворка Spring. Я реализовал игру в крестики-нолики, где пользователь играет против компьютера, использующего алгоритм Минимакс.

**Что я реализовал:**
- **Разделил архитектуру приложения на четкие слои:** `web`, `domain`, `datasource` и `di`.
- **В слое `domain`** описал бизнес-логику, включая валидацию игрового поля, проверку окончания игры и алгоритм Минимакс для расчета ходов ИИ.
- **В слое `datasource`** создал потокобезопасное in-memory хранилище на базе коллекций Java и реализовал паттерн Repository для работы с ним. Написал мапперы для преобразования моделей между слоями.
- **В слое `web`** настроил Spring MVC контроллеры. Они принимают ходы пользователя через `POST`-запросы и возвращают ответ с обновленным полем после хода компьютера. Приложение поддерживает ведение нескольких игр одновременно по их UUID.
- **В слое `di`** настроил внедрение зависимостей (IoC/DI) с помощью Spring `@Configuration`, где хранилище зарегистрировано как singleton.
